# Arquivos do presente

Envie nesta pasta:

- `missing-someone.mp3`: Bobby Chase — Missing Someone, arquivo escolhido para a trilha.
- `cupido.png`: imagem do cupido enviada pelo criador do presente.

Os nomes devem ser exatamente esses, em letras minúsculas. O site e o cache offline já apontam para eles. Sem esses arquivos, o áudio não toca e o cupido usa uma silhueta provisória. Arquivos publicados aqui são públicos.
