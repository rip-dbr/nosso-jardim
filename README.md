# Um ano juntos — Olá, você

Site de aniversário para Misty. Textos fornecidos pelo casal, sem avisos de demonstração na experiência. Configuração editável em CONTENT dentro de index.html.

- Nove etapas, navegação por botões.
- Data do contador: 27/11/2025 às 22:36 (-03:00).
- Três capítulos de álbum com galerias e bilhetes no verso.
- Histórias longas e carta divididas em páginas, respeitando parágrafos.
- Flor interativa, três bilhetes das estrelas e cupido escondido.
- Música escolhida, com volume reduzido e abertura por toque.
- Final com link https://www.roblox.com/games/102352352057653/presente .

As fotos precisam estar em assets/album-01.png até assets/album-13.png; a correspondência está em assets/README.md. Enquanto um arquivo não está disponível, sua imagem usa o desenho de jardim. Os textos não contêm instruções provisórias.

GitHub Pages publica a raiz de main. O projeto continua editável após a entrega. O pacote completo abre localmente no computador. No iPhone, priorizar Safari por HTTPS; HTML pelo app Arquivos não é equivalente. O cache não é backup permanente. A lista do service worker inclui as mídias; preparo offline só funciona quando os arquivos estiverem disponíveis.

Validação: sintaxe JavaScript e fluxo com DOM simulado; as nove etapas renderizam; carta e histórias são paginadas sem perder texto; abertura sem botão de entrada silenciosa e link final corretos. Navegador/Safari real indisponível nesta sessão; conferir encaixe no dispositivo da destinatária antes de entregar.
