# Olá, você

Protótipo de um presente de aniversário de namoro, em telas interativas.

## Testar

Abra `index.html` no navegador ou publique a raiz pelo GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

## Personalizar

Edite `CONTENT` no HTML. A data inicial é `2025-11-27T22:36:00-03:00` (Brasília). O contador usa o relógio do dispositivo e atualiza a cada segundo. Mostra dias completos de 24 horas, horas, minutos e segundos, ou horas totais. Não é contagem regressiva para o aniversário.

Fotos viram ao toque e mostram um bilhete; o cenário muda do entardecer à noite; a flor revela uma mensagem; estrelas abrem bilhetes; a carta tem páginas. Frases e imagens são demonstrativas e devem ser aprovadas pelo casal.

Os desenhos, fontes do sistema e a trilha sintetizada funcionam offline. No iPhone, prefira HTTPS/Safari e o botão de guardar offline na última tela; depois adicione à Tela de Início e teste em modo avião. O cache não é backup permanente. Fotos e música definitivas devem ser incorporadas como data URLs ou incluídas no cache. Não existe autenticação neste protótipo público.

O projeto não coleta dados. O link Roblox deve ser preenchido em `CONTENT.robloxUrl`.
